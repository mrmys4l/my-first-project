# Fresh Cutz Pressure Washing Landing Page

A responsive landing page for Fresh Cutz Pressure Washing LLC, built as my first project as part of The Odin Project.

## Live Demo

Coming soon.

## About the Project

This project is a landing page for a pressure washing and property services business based in Warner Robins, Georgia.

The goal was to create a clean, modern, responsive website that presents the company's services, branding, before-and-after work, and contact information.

## Tech Stack

- HTML5
- CSS3
- Flexbox
- CSS Media Queries
- Git & GitHub

## Features

- Responsive layout for desktop and mobile screens
- Custom business branding
- Hero section with custom imagery
- Services section
- Before-and-after gallery
- Licensed & insured section
- Call-to-action sections
- Responsive footer
